# sergeybar.github.io

Professional one-page CV website for GitHub Pages.

## Quick start

1. Open `index.html` and replace placeholder content with your real data.
2. Update colors or spacing in `styles.css` if needed.
3. Commit and push to `main`.
4. In GitHub repository settings, enable Pages:
	- Source: Deploy from branch
	- Branch: `main` and `/ (root)`

Your page will be available at:
https://sergey-bar.github.io

## Files

- `index.html`: Structure and content of your CV page
- `styles.css`: Visual design, layout, and responsive behavior
- `script.js`: Mobile menu and current year in footer

## What to customize first

- Name, role, and summary in the hero section
- Contact links and email
- Experience achievements with measurable impact
- Skills and project stack

## Tips for a stronger CV page

- Keep bullet points results-focused (metrics, business impact)
- Put strongest experience first
- Keep sections short and scannable
